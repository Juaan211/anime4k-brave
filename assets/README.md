# Arte del panel

`poodle-sprites.png` contiene cuatro ilustraciones transparentes en una cuadrícula 2×2. Se generaron con la herramienta integrada imagegen tomando como referencia la imagen azul aportada por el usuario. No se cargan imágenes ni fuentes de Internet.

Resumen del prompt: atlas cuadrado transparente 2×2, poodle marrón asomado con patas delante (arriba izquierda), poodle marrón inclinado asomado por un lateral (arriba derecha), poodle blanco con sombrero de paja y cinta roja (abajo izquierda), poodle blanco dormido sobre sus patas (abajo derecha); estilo anime pintado, ojos grandes, pelaje rizado, sin fondo, texto ni controles de interfaz.

Las decoraciones son estáticas, no reciben eventos del mouse y se esconden en la versión compacta y al minimizar el panel. El fondo del reproductor sigue siendo el video real.

## Prompt completo de imagegen

Use case: stylized-concept / production UI decoration assets. Reference image is STYLE/CHARACTER reference only, not the output layout. Generate a single SQUARE 1024x1024 PNG sprite atlas with genuinely transparent alpha (no checkerboard, no scenery, no text, no UI, no glow ribbons). Four separate cute fluffy toy poodle cutouts, arranged on an exact 2 by 2 grid of equal square cells, isolated fully inside each cell with generous transparent margins and never touching another cell. Match the warm hand-painted anime illustration characters from the reference: curly plush fur, expressive large glossy eyes, tiny dark nose, soft peach rim highlights. TOP LEFT cell: apricot/brown poodle head and two front paws, facing forward, leaning over an imaginary panel edge, friendly open mouth. TOP RIGHT cell: apricot/brown poodle peeking around an imaginary vertical panel edge, tilted head and paws, like reference left-side dog. BOTTOM LEFT cell: cream white poodle head with two paws wearing a yellow straw hat with red ribbon, facing forward; suitable as a little avatar too. BOTTOM RIGHT cell: cream white poodle lying down asleep with face on front paws, no hat, no Z lettering. All four share the exact same scale, charming style and linework. Keep artwork crisp and faithful to the reference dog designs. The only opaque pixels must be the dogs and their hats; leave the whole background truly transparent. This file will be used as local CSS sprite artwork for a functional browser extension panel.
